## 📌 Projeto em Destaque

### 🌱 EcoTech — API REST

**Java 21 | Spring Boot | Spring Security | PostgreSQL | Docker**

O EcoTech é um projeto de rede social voltada à sustentabilidade, desenvolvido com uma arquitetura back-end baseada em APIs RESTful.

O projeto explora:

- Cadastro e autenticação de usuários
- Segurança baseada em JWT
- Modelagem de dados relacionais com PostgreSQL
- Persistência de dados com Spring Data JPA e Hibernate
- Migrações de banco de dados utilizando Flyway
- Ambientes de banco de dados conteinerizados com Docker

🚧 **Status:** Em desenvolvimento
